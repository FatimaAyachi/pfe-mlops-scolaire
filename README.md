# 🎓 PFE : Pipeline MLOps pour la Prédiction Scolaire
## 📝 Description
Ce projet fait partie de mon PFE. L'objectif est de mettre en place un pipeline **MLOps** complet pour prédire la réussite ou l'échec des étudiants en fonctionne divers facteurs.

- **notbook/** : Analyse exploratoire (EDA) et Nettoyage des donnees.
